Privacy policy

Last updated: November 8, 2026.

This page covers the Fact Vault uploader, a private tool used by Théo Chuzeville to manage his own YouTube channel, Fact Vault. Contact: theochuzeville@gmail.com.

In short. The app is only used with Théo's own Google account, to manage the Fact Vault channel. It does not ask anyone else to sign in, and Google data is never shared or sold.

Google data the app reads and writes

With the permissions granted by the channel owner, the app accesses the following on the Fact Vault channel only:

  • Videos: it uploads the channel's videos (the Shorts and a monthly compilation), schedules them and sets their thumbnails.
  • Video metadata: it sets the title, description and tags of each video it uploads, can change a title later, and reads the privacy and processing status of the channel's videos.
  • Comments: it posts one comment from the channel under each new Short, and reads the public comments left on the channel's recent videos. For those comments it keeps only the text, the like count, the reply count and the date. It does not keep the commenters' names or channel IDs.
  • Playlists: it creates the channel's playlists and adds the channel's videos to them.
  • YouTube Analytics statistics: it reads the channel's aggregate statistics per video (views, watch time, average view duration, likes, comments, subscribers gained).

How the data is used

The data is used only to manage the Fact Vault channel: publishing its videos, organizing them, and choosing future topics from the statistics. It is not used for advertising, profiling or any other purpose.

Where it is stored

The authorization token and the data listed above are stored on Théo's private server, which only he can access. Nothing is stored in a third-party database.

Sharing

Google user data is not shared with, sold to or transferred to anyone. The app does not access or collect the data of any other Google user.

Google API Services

The Fact Vault uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google account settings: https://myaccount.google.com/permissions. The stored token then stops working, and the data kept on the server can be deleted on request to the contact address below.
